1. 執行摘要

1.1 業務目標

建立可擴展的 Freelance Sales Agent 網絡，通過拆賬模式（Agent 可 markup 1.4-1.5倍底價）為兩大核心業務創造持續客戶來源。

1.2 核心策略

  • 精準招募：鎖定有客戶網絡的 Agent（財務仲介、金石公司、會計師等）
  • 高佣金激勵：Agent 可自由 markup，賺取 29-33% 佣金
  • 找對客戶：直接接觸需要服務的人（非服務提供者）
  • 自動化流程：Webinar + Click Funnel 減少人力成本
  • 數據驅動：持續追蹤、優化各渠道效果

1.3 關鍵成功因素

五大成功要素

  • ☑ 招募有客戶網絡的 Agent（財務仲介優先）
  • ☑ 提供有吸引力的 markup 空間（1.4-1.5倍）
  • ☑ 精準找到需要服務的客戶（論壇、社交媒體、Webinar）
  • ☑ 建立自動化跟進流程（減少人力）
  • ☑ 持續優化（每週檢討數據）

3. 拆賬模式與定價

3.1 拆賬模式說明

核心概念

我們提供底價給 Agent，Agent 可以自由 markup 1.4-1.5 倍賣給客戶。

定價結構：

成本價 × 1.4 = Agent 底價

Agent 底價 × 1.4 或 1.5 = 客戶價格

Agent 賺取差價 = 佣金（29-33%）

公司永遠賺取 40% 利潤

這個模式讓 Agent 有動力推廣，因為 markup 越高，賺得越多。

3.4 付款方式

靈活付款安排（增加成交率）

方案 1：分期付款（3期）- 1.1倍

客戶分 3 期付款，收取 1.1 倍價格。

  • 首期：50%（簽約時）
  • 第二期：30%（完成文件準備/遞交法庭）
  • 尾期：20%（獲法庭批准/服務完成）

範例：簡單破產 Agent 底價 $18,263

分期價格 = $18,263 × 1.1 = $20,089

客戶分3期付，Agent 仍一次性收到全額佣金

方案 2：月供計劃（6-12個月）- 1.2倍

與財務公司合作，客戶可以月供，收取 1.2 倍價格。

範例：簡單破產 Agent 底價 $18,263

月供價格 = $18,263 × 1.2 = $21,916

÷ 6個月 = $3,653/月

÷ 12個月 = $1,826/月

  • 對客戶來說更容易負擔
  • Agent 仍然一次性收到全額佣金
  • 公司承擔分期收款風險

4. Agent 招募策略

4.1 目標 Agent 類型（擴展版 - 12種）

優先級一：金融相關（最高優先）

1. 財務仲介（貸款 Agent）

  • 為什麼優先：每天接觸債務問題客戶，客戶申請唔到貸款 = 需要破產/IVA
  • 客戶網絡：大（每月10-50個潛在客戶）
  • 預期成交率：高（30-50%）
  • 招募渠道：直接拜訪財務公司地舖、財務仲介協會

2. 當舖（金石公司）

  • 為什麼優先：客戶已經無抵押品，債務過重無法再借
  • 客戶網絡：中（每月5-20個）
  • 預期成交率：中高（25-40%）
  • 招募渠道：上門拜訪、當舖業協會

3. 保險經紀

  • 為什麼優先：接觸大量家庭客戶，了解財務狀況
  • 客戶網絡：中（每月5-15個）
  • 預期成交率：中（20-35%）
  • 招募渠道：保險從業員協會、LinkedIn、行業活動

優先級二：專業服務（中高優先）

4. 會計師 / 記帳員

  • 為什麼優先：處理公司/個人財務，客戶信任度高，適合推合規服務
  • 客戶網絡：中（每月3-10個）
  • 預期成交率：高（40-60%）
  • 招募渠道：會計師公會、LinkedIn、直接聯絡中小型會計行

5. 律師（非破產專業）

  • 為什麼優先：客戶問破產問題但不是他們專業，轉介賺佣金
  • 客戶網絡：小（每月2-5個）
  • 預期成交率：高（50-60%）
  • 招募渠道：律師行直接聯絡、律師會活動

6. 物業代理

  • 為什麼優先：有些客戶想賣樓還債，負資產問題
  • 客戶網絡：小（每月1-5個）
  • 預期成交率：低（10-20%）
  • 招募渠道：地產舖直接聯絡、地產 Agent 聯盟、Facebook 地產群組

優先級三：社區網絡（中優先）

7. 社工 / 輔導員

  • 為什麼優先：接觸基層家庭，了解財務困難個案
  • 客戶網絡：中（每月5-10個）
  • 預期成交率：中（25-35%）
  • 招募渠道：社福機構、社工協會、非牟利組織聯絡

8. 社區中心職員 / NGO 工作者

  • 為什麼優先：服務區內居民，了解社區需要
  • 客戶網絡：小（每月2-8個）
  • 預期成交率：中（20-30%）
  • 招募渠道：各區社區中心、NGO 直接聯絡

9. 議員助理 / 區議員辦事處

  • 為什麼優先：處理居民求助個案，包括債務問題
  • 客戶網絡：中（每月3-12個）
  • 預期成交率：高（35-45%）
  • 招募渠道：各區議員辦事處、立法會議員辦公室

優先級四：其他潛在渠道（低至中優先）

10. 小型企業老闆（有員工網絡）

  • 為什麼優先：了解員工財務狀況，可轉介有需要員工
  • 客戶網絡：小（每月1-5個）
  • 預期成交率：中（20-30%）
  • 招募渠道：商會、中小企聯會、行業協會

11. 美容院 / 髮型屋老闆

  • 為什麼優先：與客戶建立信任關係，客戶會分享財務煩惱
  • 客戶網絡：小（每月1-3個）
  • 預期成交率：低（15-25%）
  • 招募渠道：直接上門、美容業協會

12. 健身教練 / 瑜伽導師

  • 為什麼優先：與學員建立長期關係，了解生活狀況
  • 客戶網絡：小（每月1-4個）
  • 預期成交率：低（15-20%）
